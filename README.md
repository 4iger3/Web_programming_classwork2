# 4iger3 portfolio

This portfolio uses HTML and CSS only. It has no JavaScript runtime or build step.

## Preview with htmlpreview

Push the repository to GitHub, then open:

```text
https://htmlpreview.github.io/?https://github.com/4iger3/Web_programming_classwork2/blob/main/index.html
```

The stylesheet, profile illustration, project artwork, fonts, and underwater video are repository assets referenced by relative paths. Keep those paths intact when moving files.

## CSS-only interactions

- The CV tabs use native radio inputs and CSS selectors.
- The mobile navigation uses a native `<details>` disclosure.
- Floating badges, project-card hover states, and supported scroll reveals use CSS animations.
- The profile artwork and programming-themed project illustrations are static images.
- The native browser cursor remains enabled; a cursor that follows the pointer requires JavaScript.

The muted, looping HTML video plays natively in browsers that allow autoplay. Its poster image remains as the visual fallback. Project cards are fictional concepts, not shipped products.
