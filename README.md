# Mikhail — Web Developer Portfolio

One-page, mobile-friendly portfolio for Mikhail, built with HTML and CSS only.
It uses a polished 16–32-bit game-inspired visual style and CSS-drawn project
concepts. The profile image is a small pixel-art illustration.

## Preview with htmlpreview

Push the repository to GitHub, then open:

```text
https://htmlpreview.github.io/?https://github.com/4iger3/Web_programming_classwork2/blob/main/index.html
```

The stylesheet, profile illustration, and fonts are repository assets referenced
by relative paths. Keep those paths intact when moving files.

## CSS-only interactions

- The mobile navigation uses a native `<details>` disclosure.
- Hover states and small animations are CSS-only, with reduced-motion support.
- All external portfolio links lead to [github.com/4iger3](https://github.com/4iger3).

Project cards are illustrative concepts, not shipped products. To preview the
page, push the repository to GitHub and open the link above in htmlpreview.
